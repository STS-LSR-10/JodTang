## 0.5) เลือกหมวดจากปุ่ม (ทุกแพ็กเกจ)

- [ ] กดช่อง "จดตังค์" บน Rich Menu → ได้การ์ดวิธีพิมพ์ และเห็นปุ่มลัด "หมวดรายจ่าย" / "หมวดรายรับ" ใต้การ์ด
- [ ] กด "หมวดรายจ่าย" → ได้รายชื่อหมวดเป็นปุ่ม (ไม่มี "อื่นๆ") กดหมวด → คีย์บอร์ดเปิดและมีชื่อหมวดอยู่ในช่องพิมพ์แล้ว พิมพ์เลขต่อแล้วส่ง → จดเข้าหมวดนั้น
- [ ] กด "หมวดรายรับ" → เลือก "งานพิเศษ" แล้วพิมพ์ 3000 → จดเป็นรายรับ ไม่ใช่รายจ่าย
- [ ] พิมพ์เอง `เดินทาง 120` / `ที่พัก 5000` → เข้าหมวดตรงชื่อ
- [ ] ถ้าแอป LINE รุ่นเก่าไม่เติมชื่อหมวดให้ ให้จดอาการไว้ (พิมพ์ชื่อหมวดเองก็ใช้ได้)

## 0.6) แท็ก #Tag (Professional ขึ้นไป — **รัน migration 0014 ก่อน**)

- [ ] บัญชี Free พิมพ์ `หมูกระทะ 500 #ปาร์ตี้` → บอทชวนอัปเกรด ไม่จดรายการ
- [ ] บัญชี Professional/Ultimate พิมพ์เหมือนกัน → ได้การ์ดจดสำเร็จที่โชว์ `#ปาร์ตี้` และชื่อรายการเป็น "หมูกระทะ"
- [ ] หน้ารายการโชว์แท็กใต้ชื่อ พิมพ์ `#ปาร์ตี้` ในช่องค้นหา → เหลือเฉพาะรายการที่ติดแท็กนั้น
- [ ] ข้อความที่ไม่มีแท็กยังจดได้ปกติ และสรุปยอดไม่เพี้ยน

## 0.7) แนบรูปประกอบรายการ (Professional ขึ้นไป — **รัน migration 0015 ก่อน**)

- [ ] จดรายการ `ข้าวมันไก่ 50` → การ์ดมีปุ่ม "📷 แนบรูป" กด → บอทขอรูป พร้อมปุ่มถ่ายรูป/เลือกจากอัลบั้ม
- [ ] ส่งรูปอาหาร → บอทตอบว่าแนบกับ "ข้าวมันไก่" แล้ว (ไม่อ่านเป็นสลิป ไม่มีการ์ดตรวจสลิป)
- [ ] หน้ารายการมีไอคอนรูปแนบ กดแล้วเห็นรูป และกด "ลบรูปแนบ" ได้
- [ ] ส่งรูปสลิปทันทีหลังแนบเสร็จ → ถูกอ่านเป็นสลิปตามปกติ (หนึ่งการกดแนบได้หนึ่งรูป)
- [ ] กดแนบรูปซ้ำที่รายการเดิม → บอทบอกว่ารูปใหม่จะแทนรูปเดิม
- [ ] บัญชี Free กด "แนบรูป" → ได้ข้อความชวนอัปเกรด
- [ ] ปุ่มบนการ์ดแบบ "สั้น" (ตั้งค่ารูปแบบการ์ด) แสดงเป็นปุ่มลัดใต้ข้อความ

## 0.8) แยกรายการจากใบเสร็จ (เฉพาะ Ultimate — ใช้แผนทดลอง Ultimate ได้)

- [ ] ถ่ายใบเสร็จ 7-11 / ห้าง ส่งเข้าแชท → การ์ดตรวจสลิปโชว์ "รายการในใบเสร็จ" และปุ่ม "แยก n รายการ" ข้างปุ่ม "ยืนยัน"
- [ ] เทียบรายการบนการ์ดกับใบจริง: ชื่อ/ราคาถูกไหม ขาดบรรทัดไหม (จดอาการไว้ ถ้าอ่านเพี้ยนมาก)
- [ ] กด "แยก n รายการ" → ได้ข้อความสรุปและรายการแยกในหน้ารายการ ยอดรวมทุกรายการ = ยอดรวมในใบ (ภาษี/ค่าบริการอยู่ใน "ส่วนต่างในใบเสร็จ")
- [ ] กดปุ่มแยกซ้ำ → บอทบอกว่าไม่พบรายการ ไม่สร้างซ้ำ
- [ ] กด "ยืนยัน" แทน → จดเป็นยอดรวมใบเดียวตามเดิม
- [ ] ใบที่มีส่วนลดท้ายบิล (รายการรวมเกินยอดรวม) → การ์ดไม่มีปุ่มแยก และบอกเหตุผล
- [ ] บัญชี Professional ส่งใบเสร็จ → ได้การ์ดยอดรวมเหมือนเดิม ไม่มีรายการ/ปุ่มแยก
- [ ] ดูต้นทุน AI ต่อใบของ Ultimate ที่ Google AI Studio / OpenAI usage

## 1) ทดลองฟรี 7 วัน (ทำก่อน เพราะต้องเริ่มจากบัญชี Free)

- [ ] หน้าอัปเกรด (บัญชี Free) เห็นปุ่มทดลองฟรีทั้ง Professional และ Ultimate
- [ ] กดทดลอง Professional → ขึ้นว่าเริ่มแล้ว หน้าตั้งค่าแสดงแผน Professional และวันหมดอายุ = วันนี้ + 7 วัน (ปี พ.ศ.)
- [ ] ปุ่มทดลอง Professional หายไป (ใช้ได้ครั้งเดียวต่อแผน) และไม่มีปุ่มทดลองขณะมีแผนอยู่
- [ ] กดซ้ำเร็ว ๆ / เปิดสองแท็บ ได้สิทธิ์ครั้งเดียว ไม่มี error 500
- [ ] ฟีเจอร์ของแผนที่ทดลองใช้ได้ระหว่างทดลอง (Professional: จดย้อนหลัง/หลายรายการ, สลิป 5 ใบ, จดประจำ · Ultimate: เสียง, สลิปไม่จำกัด)
- [ ] (ไม่บังคับ) เมื่อครบ 7 วันแผนกลับเป็น Free เอง — ทดสอบด้วยการแก้ `plan_expires_at` ใน Supabase ให้เป็นเวลาที่ผ่านไปแล้ว

> ต้องการทดสอบซ้ำ: ครั้งทดลองบันทึกในตาราง `plan_trials` (ลบแถวของตัวเองใน SQL Editor — ดูชื่อคอลัมน์ใน `supabase/migrations/0011_trials_and_upgrades.sql` ก่อน)

## 2) จดด้วยเสียง (เฉพาะ Ultimate — ใช้แผนทดลองจากข้อ 1 ได้)

- [ ] กดค้างไมค์ใน LINE พูด "กาแฟสามสิบบาท" (ไม่เกิน 30 วินาที) → ได้การ์ด "ตรวจรายการจากเสียง" มีปุ่ม จดเลย / เปลี่ยนหมวด / ยกเลิก
- [ ] **ยังไม่จดก่อนกดยืนยัน**: เปิดหน้าสรุปแล้วยอดยังไม่เปลี่ยน
- [ ] กด `จดเลย` → รายการเข้าในหน้ารายการ ยอดสรุปเปลี่ยน
- [ ] กด `เปลี่ยนหมวด` แล้วเลือกหมวด → จดในหมวดที่เลือก
- [ ] กด `ยกเลิก` → ไม่มีรายการเข้า
- [ ] พูดรายรับ "ได้เงินเดือนหนึ่งหมื่นห้า" → ถูกจัดเป็นรายรับ
- [ ] พูดหลายรายการในประโยคเดียว → แยกรายการได้ตามที่พูด (บันทึกผลที่เห็น)
- [ ] เสียงเบา/เสียงรบกวน/ไม่มีเลขเงิน → บอทตอบสุภาพ ไม่จดมั่ว
- [ ] บัญชี Free และ Professional ส่งเสียง → บอทบอกว่าเป็นฟีเจอร์เฉพาะ Ultimate และไม่ถอดเสียง
- [ ] ส่งเสียงรัว ๆ เกิน 5 ครั้ง/นาที → ขึ้นข้อความเตือน rate limit
- [ ] ถ้าถอดเสียงพัง: ดู Vercel Logs ค้น `voice_transcribe_failed` (ข้อสงสัยหลัก: ไฟล์ m4a ของ LINE ส่งเป็น `audio/mp4` ไป Gemini)

## 3) สรุปอัตโนมัติ (ต้องเป็น Professional ขึ้นไป · ปิดไว้เป็นค่าเริ่มต้น)

- [ ] มีรายการจดในสัปดาห์ที่ผ่านมา (จันทร์–อาทิตย์) อย่างน้อยหนึ่งรายการ (ช่วงที่ไม่มีรายการเลยจะไม่ส่ง)

- [ ] GitHub Actions รันสำเร็จ (ไม่ใช่ 401) → ถ้า 401 ตรวจ secrets `APP_BASE_URL` และ `CRON_SECRET` ให้ตรงกับ Vercel · log ค้น `cron_reminders_failed`
- [ ] ตรวจโควตา push ที่ LINE Official Account Manager หลังทดสอบ

## 4) อัปเกรดจ่ายเฉพาะส่วนต่าง

ใช้ Stripe **Test mode** เท่านั้น · บัตรทดสอบ `4242 4242 4242 4242` (วันหมดอายุในอนาคต, CVC อะไรก็ได้)

### 4.1 พร้อมเพย์ → อัปเกรดส่วนที่เหลือ

- [ ] บัญชีที่ไม่มีแผน เลือก Professional รายเดือน ช่องทางพร้อมเพย์ → ในหน้าจ่ายเงินของ Stripe (โหมดทดสอบมีหน้าจำลองให้กดอนุมัติ) จ่ายสำเร็จ
- [ ] กลับมาที่ `/pay/result` แล้วหน้าตั้งค่าแสดง Professional และวันหมดอายุ = วันนี้ + 1 เดือน
- [ ] หน้าอัปเกรดไม่ให้เลือกวิธีชำระ (ต้องพร้อมเพย์ต่อเนื่อง) และเห็นปุ่ม "อัปเกรดส่วนที่เหลือ" ไป Ultimate
- [ ] ราคาที่แสดง = (฿139 − ฿59)/30 × วันที่เหลือ (ปัดขึ้นเป็นบาท, ขั้นต่ำ ฿10) — คำนวณมือเทียบ เช่น เหลือ 30 วัน ≈ ฿80
- [ ] จ่ายสำเร็จ → แผนเป็น Ultimate, **วันหมดอายุไม่เปลี่ยน**
- [ ] Stripe → Payments มีรายการนั้น และตาราง `payments` มี `kind='upgrade'`
- [ ] ผู้ใช้ Ultimate ซื้อ Professional ไม่ได้ (ห้ามลดแผน)
- [ ] ต่อเวลาเต็มราคาด้วยพร้อมเพย์ (รอบเดียวกัน) → วันหมดอายุต่อท้ายจากเวลาที่เหลือ

### 4.2 บัตร → เปลี่ยนแผน/รอบ (จ่ายเฉพาะส่วนต่าง)

- [ ] บัญชีที่ไม่มีแผน (หรือรอพร้อมเพย์หมด) สมัคร Professional รายเดือนด้วยบัตรทดสอบ → แผนใช้งานได้ ต่ออายุอัตโนมัติ
- [ ] หน้าอัปเกรดไม่ให้สมัครซ้ำแผนเดิม; ปุ่ม "จัดการการชำระเงิน" เปิด Stripe Billing portal ได้
- [ ] อัปเกรดเป็น Ultimate (หรือรายเดือน→รายปี) → Stripe คิดเฉพาะส่วนต่างทันที ตรวจใบแจ้งหนี้ใน Stripe ว่ามีเครดิตเวลาที่ไม่ได้ใช้
- [ ] ลองบัตรที่ถูกปฏิเสธ `4000 0000 0000 0341` ตอนเปลี่ยนแผน → แผนเดิมไม่เปลี่ยน
- [ ] รายปี→รายเดือนกลางรอบ และลดแผน ทำไม่ได้ (ปุ่มปิด/ข้อความอธิบาย)
- [ ] Webhook ใน Stripe → Developers → Webhooks ตอบ 2xx ทุกอีเวนต์ (ถ้า 400 = `STRIPE_WEBHOOK_SECRET` ไม่ตรง; ถ้า 5xx ดู log `stripe_webhook_failed`)
