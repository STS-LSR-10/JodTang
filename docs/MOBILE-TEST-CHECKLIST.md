## 0.3) สรุปเป็นการ์ด (ทุกแพ็กเกจ)

- [ ] พิมพ์ `สรุปวันนี้` → ได้การ์ดสรุป (หัวข้อ "สรุปวันนี้" + วันที่ พ.ศ.) รายรับ/รายจ่าย/เหลือ ตรงกับรายการของวันนี้ และไม่มีบรรทัดเทียบกับเมื่อวาน
- [ ] พิมพ์ `สรุปเดือนนี้` → การ์ดตามรอบงบ มีหมวดสูงสุด และบรรทัด "เพิ่มขึ้น/ลดลง % จากเดือนก่อน" (ถ้าเดือนก่อนมีรายจ่าย) ตัวเลขตรงกับหน้า "สรุป" ใน LIFF
- [ ] กดปุ่ม "ดูรายละเอียด" เปิดหน้าสรุปใน LINE ได้
- [ ] วัน/เดือนที่ยังไม่มีรายการ → ได้ข้อความสั้นๆ ว่ายังไม่มีรายการ
- [ ] การ์ดสรุปอัตโนมัติ (สัปดาห์/เดือน) ยังหน้าตาเหมือนเดิม

## 0.28) หมวดของตัวเอง + อีโมจิ (สร้าง/แก้ = Professional ขึ้นไป)

- [ ] Professional/Ultimate: หน้า "หมวด/งบ" → "เพิ่มหมวด" → เลือกอีโมจิจากตาราง (หรือพิมพ์อีโมจิจากคีย์บอร์ดมือถือเอง) → บันทึก แถวหมวดมีอีโมจิหน้าชื่อ
- [ ] จดรายการด้วยคำค้นของหมวดนั้น → การ์ดจดสำเร็จขึ้น "🐱 ชื่อหมวด" และรายการในหน้า "รายการ" มีอีโมจิหน้าหมวด
- [ ] กดช่อง "จดตังค์" → "หมวดรายจ่าย" → ปุ่มหมวดนั้นมีอีโมจิ กดแล้วช่องพิมพ์เติม **ชื่อหมวดล้วน** (ไม่มีอีโมจิในช่องพิมพ์) พิมพ์เลขต่อแล้วจดเข้าหมวดถูก
- [ ] `สรุปหมวด` และ `ล่าสุด` โชว์อีโมจิของหมวดตัวเอง; หมวดมาตรฐานไม่มีอีโมจิและไม่มีชื่อไอคอนหลุดออกมา
- [ ] แก้หมวด → ล้างอีโมจิ → กลับเป็นไม่มีอีโมจิ; พิมพ์ข้อความหลายตัวในช่องอีโมจิ → ขึ้น "ใส่ได้เป็นอีโมจิตัวเดียวเท่านั้นนะ"
- [ ] Free: "เพิ่มหมวด" ขึ้นหน้าล็อก; หมวดของตัวเองที่มีอยู่ เปิดแก้ไขแล้วช่องถูกปิด ลบได้ และซ่อน/เรียงยังได้; หมวดมาตรฐานแก้คำค้นได้ตามเดิม

## 0.29) AI Insight (เฉพาะ Ultimate — **รัน migration 0018 ก่อน**)

- [ ] พิมพ์ `วิเคราะห์` → การ์ด AI Insight มีข้อสังเกต 2–4 ข้อ (ตัวเลข ฿/% ต้องตรงกับ `เทียบเดือน` และ `สรุปหมวด`) และคำแนะนำ 1 ข้อ พร้อมข้อความ "สร้างโดย AI ... ไม่ใช่คำแนะนำทางการเงินส่วนบุคคล"
- [ ] ข้อสังเกตระดับรายการ เช่น "ชานม ใช้ไป ฿… (n ครั้ง) เพิ่มขึ้น …%" ถูกต้องเมื่อเทียบกับรายการที่จดจริง
- [ ] ไม่มีข้อสังเกตที่ตัวเลขแปลกหรือไม่ตรงกับข้อมูล, ไม่มีคำแนะนำเรื่องลงทุน
- [ ] ปิด/ถอด API key ของ AI แล้วลองใหม่ → ยังได้การ์ดที่เป็นข้อสังเกตจากตัวเลข (ไม่มีข้อความ "สร้างโดย AI")
- [ ] กดซ้ำเกิน 5 ครั้งในวันเดียว → บอกว่าครบจำนวนแล้ว
- [ ] ผู้ใช้ Ultimate ที่เปิด "สรุปอัตโนมัติรายเดือน": ถึงวันเริ่มรอบงบ 09:00 ได้การ์ดสรุป + การ์ด AI Insight ต่อท้าย (สั่งรัน workflow `cron.yml` เพื่อทดลองได้) ส่วน Professional ได้การ์ดสรุปอย่างเดียว
- [ ] บัญชี Free/Professional พิมพ์ `วิเคราะห์` → ได้ข้อความชวนอัปเกรด Ultimate; ปุ่มลัด "🧠 วิเคราะห์" ใต้การ์ดสรุปทำงาน
- [ ] ดูต้นทุน AI ที่ Google AI Studio / OpenAI usage และ log `insight_failed` ใน Vercel

## 0.30) พยากรณ์ปลายเดือน (เฉพาะ Ultimate — ใช้แผนทดลอง Ultimate ได้ — **รัน migration 0017 ก่อน**)

- [ ] พิมพ์ `พยากรณ์` → การ์ด "พยากรณ์เงินปลายรอบ": คาดสิ้นรอบเหลือ (ตัวใหญ่ เขียว/แดง), เหลือตอนนี้ (ตรงกับ "เหลือ" ใน `สรุปเดือนนี้`), ใช้จ่ายทั่วไปต่อวัน, วันที่เหลือ
- [ ] ลองคำนวณมือ: (เหลือตอนนี้) − (ใช้จ่ายทั่วไปต่อวัน × วันที่เหลือ) ± รายการประจำที่จะมา = ตัวเลข "คาดสิ้นรอบ"
- [ ] ถ้าเงินไม่พอถึงสิ้นรอบ มีบรรทัด "เงินจะหมดประมาณ <วันที่> (อีก n วัน)" ถ้าพอ ขึ้น "เงินพอใช้ไปถึงสิ้นรอบ"
- [ ] ตั้งรายการประจำ (เช่น เงินเดือนเข้าวันที่ 25 และค่าผ่อนวันที่ 28) → ปรากฏใน "รายการประจำที่กำลังมา" และวันเงินหมดขยับตาม
- [ ] รายการที่เกิดจากกฎประจำที่จดไปแล้ว (เช่น ค่าเน็ตที่ตัดแล้ว) ไม่ทำให้ "ใช้จ่ายทั่วไปต่อวัน" สูงเกินจริง
- [ ] ผ่านไป 10 วันขึ้นไป มีบรรทัด "ถ้าใช้จ่ายเท่า 7 วันล่าสุด"; ตั้งงบรวมไว้ (โหมดงบรวม) → มีบรรทัดงบรวม
- [ ] ต้นรอบ/ข้อมูลน้อย → มีคำเตือน "ข้อมูลยังน้อย"
- [ ] ปุ่มลัด "🔮 พยากรณ์" ใต้การ์ดสรุป ส่งคำสั่งให้เอง; บัญชี Free/Professional ได้ข้อความชวนอัปเกรด Ultimate

## 0.31) สิทธิ์ส่งออกไฟล์และหน้าวิเคราะห์ (Professional ขึ้นไป)

- [ ] บัญชี Free: เมนู "วิเคราะห์" แสดงหน้าล็อก "กราฟและตารางวิเคราะห์สำหรับแผน Professional" มีปุ่มไปหน้าอัปเกรด และบอกคำสั่งสรุปในแชท
- [ ] บัญชี Free: หน้ารายการ กดไอคอนส่งออก → เห็นคำอธิบายและปุ่มไปหน้าอัปเกรด ไม่มีปุ่มดาวน์โหลด
- [ ] บัญชี Free: การ์ด `สรุปหมวด` ไม่มีปุ่ม "ดูกราฟในแอป"
- [ ] บัญชี Professional/Ultimate: หน้าวิเคราะห์เห็นกราฟแท่ง/โดนัท และส่งออก CSV/Excel ได้ตามเดิม
- [ ] หลังกดแลกวัน Professional ด้วยตังสะสม (หรือทดลองฟรี) แล้วกลับมาหน้าเดิม → ปลดล็อกทันที

## 0.32) สรุปรายปี และ เทียบเดือนรายหมวด (Professional ขึ้นไป)

- [ ] พิมพ์ `สรุปปี` → การ์ดปีนี้ (พ.ศ.) รายรับ/รายจ่าย/เหลือ ตัวเลขตรงกับผลรวมของหน้าวิเคราะห์ แถบรายเดือนมีเฉพาะเดือนที่ผ่านมาถึงเดือนนี้
- [ ] การ์ดมีบรรทัดเทียบ % กับปีก่อน "ช่วงวันที่เดียวกัน" (ถ้าปีก่อนมีรายจ่าย)
- [ ] `สรุปปีที่แล้ว` และ `สรุปปี 2568` ได้การ์ดทั้งปี 12 เดือน; `สรุปปี 2030` / `สรุปปี 2010` → บอกว่าปีไม่ถูกต้อง
- [ ] พิมพ์ `เทียบเดือน` → การ์ดเขียนช่วงวันที่ทั้งสองฝั่งชัดเจน (เช่น 1 ต.ค. – 17 ต.ค. เทียบ 1 ก.ย. – 17 ก.ย.) แต่ละหมวดมี ▲ แดง / ▼ เขียว และ % หมวดใหม่ขึ้น "ใหม่"
- [ ] ตัวเลขรายหมวดของ `เทียบเดือน` รวมแล้วเท่ากับแถว "รายจ่ายรวม" และตรงกับ `สรุปหมวด` ของช่วงเดียวกัน
- [ ] ปุ่มลัด 📈 เทียบเดือน และ 🗓️ ทั้งปี ใต้การ์ด `สรุปเดือนนี้` ส่งคำสั่งให้เอง
- [ ] บัญชี Free พิมพ์ทั้งสองคำสั่ง → ได้ข้อความชวนอัปเกรด

## 0.33) ล่าสุด และ สรุปหมวด (ทุกแพ็กเกจ)

- [ ] พิมพ์ `ล่าสุด` → การ์ด 5 รายการล่าสุด (ชื่อ ยอด +/- หมวด วันเวลา) เรียงใหม่สุดก่อน ไม่มีรายการที่ลบแล้ว ตรงกับหน้าสรุปใน LIFF
- [ ] พิมพ์ `สรุปหมวด` → การ์ดรายจ่ายแยกหมวดของรอบงบนี้ มียอด % และแถบ รวม % ได้ 100 พอดี ยอดรวมตรงกับ "สรุปเดือนนี้"
- [ ] ถ้ามีเกิน 8 หมวด → บรรทัดสุดท้ายเป็น "อื่นๆ (n หมวด)"
- [ ] กดปุ่ม "ดูกราฟในแอป" / "ดูทั้งหมดในแอป" เปิดหน้าที่ถูกต้อง
- [ ] ใต้การ์ด `สรุปวันนี้` / `สรุปเดือนนี้` มีปุ่มลัด 📆 ช่วงวันเอง · 📊 ตามหมวด · 🕘 ล่าสุด กด 📊 และ 🕘 ส่งคำสั่งให้เอง
- [ ] ยังไม่มีรายการ/รายจ่าย → ได้ข้อความสั้นๆ

## 0.34) ค้นหาพร้อมยอดรวม (Professional ขึ้นไป — **รัน migration 0016 ก่อน**)

- [ ] พิมพ์ `ค้นหา กาแฟ` → การ์ดผลการค้นหา: รายรับ/รายจ่าย/สุทธิ/จำนวน และ 5 รายการล่าสุดที่ตรง ตัวเลขตรงกับที่ค้นเองในหน้ารายการ
- [ ] พิมพ์ `ค้นหา #ปาร์ตี้` (รายการที่ติดแท็กไว้) → ยอดรวมเฉพาะรายการที่มีแท็กนั้น
- [ ] กด "ดูทั้งหมดในแอป" → เปิดหน้ารายการ ช่องค้นหามีคำเดิมอยู่แล้ว และมีแถบยอดรวมของผลค้น
- [ ] ค้นสิ่งที่ไม่มี → ได้ข้อความ "ไม่พบรายการที่ตรงกัน"
- [ ] พิมพ์ `ค้นหา` เฉยๆ → บอกวิธีใช้
- [ ] ค้นด้วย `50%` หรือ `_` → ไม่ทำงานเป็นตัวแทนตัวอักษร (ไม่เจอทุกรายการ)
- [ ] บัญชี Free: `ค้นหา กาแฟ` ได้ข้อความชวนอัปเกรด ส่วนช่องค้นหาในหน้ารายการยังใช้ได้แต่ไม่มีแถบยอดรวม

## 0.35) สรุปช่วงวันเอง (Professional ขึ้นไป)

- [ ] ใต้การ์ด `สรุปวันนี้` / `สรุปเดือนนี้` มีปุ่มลัด "📆 ช่วงวันเอง" กดแล้วเลือกวันเริ่ม → วันสิ้นสุด (ปฏิทินที่สองเริ่มจากวันเริ่มถึงวันนี้) → ได้การ์ด "สรุปช่วงที่เลือก" บอกวันที่และจำนวนวัน
- [ ] พิมพ์ `สรุป 1/10 ถึง 15/10` ได้การ์ดเดียวกัน ตัวเลขตรงกับรายการในหน้ารายการช่วงเดียวกัน (ลองรอบตัดบัตร เช่น `สรุป 25/9 - 24/10`)
- [ ] ลองช่วงข้ามปี `สรุป 25/12 - 24/1` ได้ 31 วัน
- [ ] การ์ดมีบรรทัดเทียบ % กับ "ช่วงก่อนหน้า" ที่ยาวเท่ากัน (ถ้าช่วงก่อนหน้ามีรายจ่าย)
- [ ] `สรุป 1/10` (ไม่มีวันจบ) → บอกวิธีพิมพ์ ช่วงเกิน 366 วัน → บอกเหตุผล
- [ ] บัญชี Free พิมพ์หรือกดปุ่ม → ได้ข้อความชวนอัปเกรด ไม่เห็นปฏิทิน

## 0.4) จดย้อนหลังด้วยปฏิทิน (Professional ขึ้นไป)

- [ ] กดช่อง "จดตังค์" → ใต้การ์ดมีปุ่มลัด "📅 จดย้อนหลัง" กดแล้วบอทตอบพร้อมปุ่ม "เลือกวันที่"
- [ ] กด "เลือกวันที่" → ปฏิทินของ LINE เปิด เลือกได้ถึงวันนี้ ย้อนได้ 1 ปี (วันในอนาคตเลือกไม่ได้)
- [ ] เลือกวัน เช่น 12 ต.ค. → บอทบอกวันที่แบบ พ.ศ. กดปุ่ม "พิมพ์รายการ" → คีย์บอร์ดเปิดและมี `12/10/2026 ` อยู่ในช่องพิมพ์แล้ว
- [ ] พิมพ์ต่อ `กาแฟ 60` ส่ง → จดเป็นวันที่ 12 ต.ค. (เช็กในหน้ารายการ)
- [ ] บัญชี Free กด "📅 จดย้อนหลัง" → ได้ข้อความชวนอัปเกรด ไม่เห็นปฏิทิน
- [ ] ถ้าแอป LINE รุ่นเก่าไม่เติมข้อความให้ ให้จดอาการไว้ (พิมพ์ `12/10 กาแฟ 60` เองก็ใช้ได้)

## 0.5) เลือกหมวดจากปุ่ม (ทุกแพ็กเกจ)

- [ ] กดช่อง "จดตังค์" บน Rich Menu → ได้การ์ดวิธีพิมพ์ และเห็นปุ่มลัด "หมวดรายจ่าย" / "หมวดรายรับ" ใต้การ์ด
- [ ] กด "หมวดรายจ่าย" → ได้รายชื่อหมวดเป็นปุ่ม (ไม่มี "อื่นๆ") กดหมวด → คีย์บอร์ดเปิดและมีชื่อหมวดอยู่ในช่องพิมพ์แล้ว พิมพ์เลขต่อแล้วส่ง → จดเข้าหมวดนั้น

- [ ] พิมพ์เอง `เดินทาง 120` / `ที่พัก 5000` → เข้าหมวดตรงชื่อ
- [ ] ถ้าแอป LINE รุ่นเก่าไม่เติมชื่อหมวดให้ ให้จดอาการไว้ (พิมพ์ชื่อหมวดเองก็ใช้ได้)

## 0.6) แท็ก #Tag (Professional ขึ้นไป — **รัน migration 0014 ก่อน**)

## 0.7) แนบรูปประกอบรายการ (Professional ขึ้นไป — **รัน migration 0015 ก่อน**)

- [ ] ส่งรูปอาหาร → บอทตอบว่าแนบกับ "ข้าวมันไก่" แล้ว (ไม่อ่านเป็นสลิป ไม่มีการ์ดตรวจสลิป)
- [ ] หน้ารายการมีไอคอนรูปแนบ กดแล้วเห็นรูป และกด "ลบรูปแนบ" ได้

- [ ] กดแนบรูปซ้ำที่รายการเดิม → บอทบอกว่ารูปใหม่จะแทนรูปเดิม
- [ ] บัญชี Free กด "แนบรูป" → ได้ข้อความชวนอัปเกรด
- [ ] ปุ่มบนการ์ดแบบ "สั้น" (ตั้งค่ารูปแบบการ์ด) แสดงเป็นปุ่มลัดใต้ข้อความ

## 0.8) แยกรายการจากใบเสร็จ (เฉพาะ Ultimate — ใช้แผนทดลอง Ultimate ได้)

- [ ] กดปุ่มแยกซ้ำ → บอทบอกว่าไม่พบรายการ ไม่สร้างซ้ำ
- [ ] กด "ยืนยัน" แทน → จดเป็นยอดรวมใบเดียวตามเดิม
- [ ] ใบที่มีส่วนลดท้ายบิล (รายการรวมเกินยอดรวม) → การ์ดไม่มีปุ่มแยก และบอกเหตุผล
- [ ] บัญชี Professional ส่งใบเสร็จ → ได้การ์ดยอดรวมเหมือนเดิม ไม่มีรายการ/ปุ่มแยก
- [ ] ดูต้นทุน AI ต่อใบของ Ultimate ที่ Google AI Studio / OpenAI usage

## 0.9) ให้ AI อ่านประโยคยาว (เฉพาะ Ultimate)

- [ ] พิมพ์ `ไปกินข้าวกับแฟนมา จ่ายไป 850 บาท เอาออกจากกระเป๋าเงินสดนะ` → ได้ข้อความ "ให้ AI ช่วยอ่าน..." และการ์ด "ตรวจรายการที่ AI อ่านให้" (ชื่อสั้น จำนวน ฿850 หมวดอาหาร) **ยังไม่จด** จนกดจดเลย
- [ ] กด "จดเลย" → รายการเข้าหน้ารายการ กด "ยกเลิก" → ไม่มีรายการ
- [ ] พิมพ์ `เมื่อวานตอนเย็นซื้อรองเท้าให้ลูก 1200 ที่ห้าง` → วันที่เป็นเมื่อวาน
- [ ] พิมพ์ `กาแฟ 30` → จดทันทีแบบเดิม ไม่มีการ์ด AI
- [ ] ข้อความที่ไม่มีเรื่องเงินเลย เช่น `วันนี้อากาศดีมาก` → บอทตอบว่าไม่เข้าใจ ไม่จดมั่ว
- [ ] บัญชี Professional พิมพ์ประโยคยาวแบบเดียวกัน → จดแบบเดิม (กติกา) ไม่มีการ์ด AI
- [ ] ส่งเสียงพูดประโยคยาวเหมือนข้างบน (Ultimate) → การ์ด "ตรวจรายการจากเสียง"
- [ ] ดูต้นทุน AI ที่ Google AI Studio / OpenAI usage และ log `smart_parse_failed` ใน Vercel
