# JodTang Design Tokens

แหล่งความจริงเดียวของดีไซน์ ต้องตรงกับ `src/styles/tokens.css` และ `tailwind.config.ts`

- ชื่อ: **จดตังค์ (JodTang)** (เดิมชื่อ Mee-Tang / มีตัง) · แท็กไลน์: "จดง่าย เห็นเงินชัด"
- โลโก้: **จดตังค์ (JodTang)** — ฟองแชทสีกรม + ใบเสร็จสีมิ้นต์ + เหรียญทอง (flat vector, SVG: `public/logo.svg`, คอมโพเนนต์ `src/components/logo.tsx`, ไอคอนเว็บ `src/app/icon.svg`, ต้นฉบับ `assets/brand/jodtang-logo-original.jpg`)

ค่า Dark เป็นค่าที่เลือกเพิ่ม (สเปกกำหนดเฉพาะ Light) ปรับได้ตามที่ตรวจ contrast

## ตัวอักษร

- ฟอนต์: **Noto Sans Thai** (หัวข้อ weight 600–700, เนื้อหา 400–500)
- ตัวเลขเงินใช้ `tabular-nums` (class `.num` หรือ `font-variant-numeric`)

## รูปทรง

- มุมโค้ง `16px` (`rounded-2xl` = 16px; การ์ด/ปุ่มใหญ่), เล็กลง `12px`, `8px`
- เงาบาง: `0 1px 2px rgb(15 23 42 / 0.06), 0 1px 3px rgb(15 23 42 / 0.08)`
- ไอคอน: Lucide เท่านั้น · ไม่ใช้กรอบสีจัด

## LINE

- **Rich Menu**: 2500×1686, grid 3×2, ภาพ flat เขียว/ขาว
  - `จดตังค์` (บอทตอบการ์ดวิธีพิมพ์ ปุ่ม "จดเลย" เปิดคีย์บอร์ดโดยไม่เติมข้อความ) | `สรุป` | `วิเคราะห์` | `รายการ` | `หมวด/งบ` | `ตั้งค่า` (เปิด LIFF ตามหน้า)
- **Flex Message**: การ์ดพื้นขาว หัวการ์ด `primary-soft` ปุ่มหลัก `primary`
